## 정직하게 적어 둘 것

- M01 문맥은 가짜 공급자로 전달 내용을 검사했다. 실제 LLM이 "그것보다 조금 더" 같은 말을 맞게 읽는지는 아직 측정하지 않았다.
- 검토 묶음이 지적한 원본의 한계(고정 데모 맵, 임의 가중 위험 점수, 형식만 검사하는 생성 모듈)는 이 저장소에 가져오지 않았다. 후속 작업은 모두 "후보 → 구조 정합 → 구현 → 자동시험 → 실제 엔진 실행 → 실측 평가" 순서로 올리고, 증거 없는 단계는 올리지 않는다.
- 원본 저장소는 별도 승인 없는 재배포를 허용하지 않는다고 적혀 있다. 이 변경은 원본 소스를 담지 않고 일반 요구사항만 담는다.

## 이어서 한 것: Y4 (M05 기준선 A·B)

`cont.learn.m05`: 합성 공정 신호(4단계, 로트별 이득·시정수 차이, 로트마다 이상 구간 하나)에서 A(단계별 통계)와 B(1차 지연 물리 + 경량 트리)를 같은 로트 분할로 잰다. 시험 9개 통과. 처음 실행한 결과(분할 지문 dc08517a97089cad, 시험 로트 3개, 이상 3건):

| 지표 | A | B |
|---|---|---|
| 단계 F1 | 0.76 | 0.99 |
| 경계 시각 오차 (초) | 3.3 | 1.0 |
| 정상 응답 오차 (RMSE) | 0.167 | 0.055 (물리만 0.042) |
| 이벤트 재현율 | 0/3 | 3/3 |
| 운전시간당 오경보 | 0 | 0 |

읽는 법: 합성 신호이고 B는 신호를 만든 법칙을 물리 모형으로 알고 있어 구조적으로 유리하다. 실제 설비 성능이 아니며 판정하지 않는다. 눈여겨볼 것은 B의 트리 보정(0.055)이 물리 단독(0.042)보다 나쁘다는 점이다. 로트 이득 차이를 트리가 배우지 못한다. 시험 시간이 0.65시간뿐이라 오경보 0은 오경보가 없다는 증거가 아니다.

## 이어서 한 것: Y5 (M06 체결력 = 물리 기준 + 보정)

`cont.learn.m06`: 측정한 조임 토크와 대표 마찰로 체결 팩의 VDI 2230 식에서 기준 체결력을 구하고, 조임 각도의 기준 대비 편차와 토크로 기준의 상대 오차를 예측하는 작은 선형 보정을 붙였다. 합성 자료(12로트, 로트마다 마찰이 ±25% 다름)에서 로트 단위로 나눠 시험했다. 시험 7개 통과. 시험 로트 3개, 24행의 결과(분할 지문 8e9c301949d5dd13):

| 평균 상대 오차 | 8.1% | 4.8% |
