# 신호 분석 엔진 (첫 번째로 새로 만든 엔진)

> 상태: 보조

FAB 진열대에서 "엔진 없음"이던 표현 유형 가운데 신호 분석이 필요한 3개를 풀었다.

| 표현 유형 | 카드 | 엔진 |
|---|---|---|
| 진동의 주파수 성분 | `signal_spectrum` | `cont.signal.spectrum`, `peaks` (한 창 푸리에 변환, 봉우리 보간) |
| 시간별 주파수 변화 | `signal_spectrogram` | `cont.signal.spectrogram` (짧은 구간 푸리에 변환) |
| 반복 작업의 편차 분포 | `repeat_distribution` | `cont.signal.distribution` (막대 분포, 평균·표준편차·사분위, 상자 수염) |

## 지키는 것
- 물리 가정이 없는 수학 계산이다. 알려진 신호를 넣어 성분과 분포를 맞게 읽는지 `tests/test_signal.py`가 확인한다 (사인파의 주파수·진폭, 회전 1배·2배·결함 성분, 속도 상승 따라가기, 이상값 개수).
- 정상 범위, 결함 주파수의 의미, 합격·불합격은 정하지 않는다. 성분과 분포만 보고한다.
- 샘플의 조건(샘플링 주파수, 회전수, 평균·산포 등)은 코드가 아니라 `config/fab/catalog.yaml`의 `samples`에 있다.

## 아직 안 된 것
- 샘플은 모두 성분을 알고 만든 **가상 신호**다 (`cont.signal.synthetic`). 카드에도 그렇게 적힌다. 실제 설비 신호로 검증한 것이 아니다.
- 자기 신호는 서버로 띄운 화면에서만 올려 볼 수 있다 (아래 절).
- 주파수 분해능은 신호 길이와 조각 길이가 정한다. 카드에 "주파수 간격"을 적었다.

## 내 신호(CSV) 올려 보기
서버로 띄운 FAB 화면(`python -m cont.fab.store`)에서 위 카드 3개의 상세 창 아래 "내 신호로 보기"를 쓴다.

| 항목 | 내용 |
|---|---|
| 읽는 파일 | 쉼표·탭·세미콜론으로 나눈 CSV (8 MB, 100만 줄 이하). 첫 줄에 숫자가 아닌 칸이 있으면 열 이름 줄. 소수점은 점(.)만 |
| 주파수 성분, 시간별 주파수 변화 | 값 열 + (시간 열 초 단위 또는 샘플링 주파수 직접 입력). 시간 열 간격이 중앙 간격보다 10% 넘게 흔들리면 거절, 1~10%는 경고를 적고 계산 |
| 편차 분포 | 값 열 하나 (10개 이상) |
| 표시 범위 | 상한을 안 적으면 가장 높은 뚜렷한 봉우리의 1.6배까지 (나이퀴스트 이하). 보인 범위는 카드에 적힌다 |
| 못 읽을 때 | 몇 번째 줄, 어느 열의 어떤 값인지 적어 돌려준다. 빈칸을 조용히 건너뛰지 않는다 |
| 보관 | 파일은 서버로 보내 계산만 하고 저장하지 않는다 |

- 결과 카드에는 "올린 파일 (내 자료, 검증하지 않음)"이라고 적힌다.
- 내 신호 결과는 아직 내 FAB에 담을 수 없다 (저장해도 다시 열 때 만들 수 없기 때문).
- 공개 데모(정적 페이지)에는 파이썬 엔진이 없어서 이 기능이 안 된다. 입력란 대신 안내가 보인다.
