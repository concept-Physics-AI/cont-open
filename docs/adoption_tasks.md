# M01~M10 후속 적용 작업

> 상태: 참고

**우선순위 개정 (2026-11-25):** R 번호는 착수 순위가 아니다. M01·M03·M04·M10과 프로젝트 관리를 먼저 연결하고 M02는 근거 보강, M05~M09는 전문 기능으로 둔다. [첫 인수 흐름](generative_workflow.md)이 현재 제품 기준이다.

기존 개발 검토를 현재 제품 작업으로 연결한 목록이다. 이 문서는 구현 완료나 성능을 선언하지 않는다. 원본 코드·내부 경로·시험 데이터는 포함하지 않는다.

현재 ARCHITECTURE.md의 C1~C7과 PhysicsAnswer를 유지한다. 영역 확장 순서는 docs/roadmap.md를 따른다. 새 경계가 필요하면 구조를 먼저 정하고 한 작업씩 별도 PR로 구현한다.

## 첫 적용 범위

R01은 체결의 현재 입력·유효 추천과 제한된 최근 대화를 공급자에 전달하는 작업이다. 단일 Session 안의 문맥 전달을 먼저 검증하며 사용자 인증·영속 저장·영역 간 작업 계획은 R02~R05에서 별도로 다룬다.

## 도입 원칙

- 이미 있는 풀이기·결과 형식·LLM 어댑터를 먼저 사용한다. 기존 모듈 전체를 중복 등록하지 않는다.
- 입력 규격, 검증 함수, 실제 추론·생성 호출, 화면 연결을 따로 확인한다.
- 연구 모형과 설명용 데모는 실측 품질 모형으로 등록하지 않는다.
- 허용 오차·보정 상한·전이 조건은 프로파일로 두고 기준이 없으면 편차만 보고한다.
- 출력은 같은 실행·개정·단위·좌표·시간축을 참조하도록 한다.
- 원본을 그대로 옮기는 후보는 공개 범위·사용 권한·의존성을 확인한 뒤 파일 단위로 다룬다.

## 권장 연결 순서

1. R01~R05: 실제 대화·문맥·계획·진행 표시. 최소 프로젝트 저장을 함께 준비한다.
2. R14~R15·R30~R31: 실제 이미지·도식·그래프·3D·설명용 4D 생성 연결. R07~R09는 해당 입력과 좌표 변환에 함께 적용한다.
3. R34·R32: 선택 편집, 의존 결과만 갱신, 장면·그래프의 동일 대상·버전·시간축 확인.
4. R03·R37: 저장·재열기·복원과 실제 브라우저 인수. R06 검색은 근거가 필요한 단계에 연결한다.
5. R10~R13·R16~R29: 수요와 데이터에 따른 전문 기능. R35~R36은 수치·CAD를 사용하는 작업에 연결하며 기본 생성 흐름의 일괄 선행조건으로 삼지 않는다.



각 작업은 준비 → 구현 → 자동시험 → 실제 공급자/해석기 실행 → 실측 평가 상태를 구분한다. 적용 대상에 따라 필요 없는 단계는 이유를 기록한다.
