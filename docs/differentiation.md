# ConT 글로벌 차별화 방향과 검증 제안

> 상태: 참고

2026-11-25 요청에 대한 전략 제안이다. [여섯 핵심 기능](generative_workflow.md)은 확정된 제품 기준이며, 아래 차별화는 검증할 가설이다. 세계 최초·최고·독점 기술 또는 현재 달성 성능을 주장하지 않는다.

## 제안하는 특별함

**같은 현실 대상을 대화·이미지·그래프·3D·4D에서 일관되게 만들고, 사용자가 가리킨 부분을 수정하면 관련 결과가 함께 바뀌며, 다음 작업까지 이어지는 AI.**

이미지·영상 생성과 상호작용 세계, 디지털트윈 기술은 이미 넓게 개발되고 있다. DeepMind의 Genie 3는 실시간 탐색 가능한 생성 환경을 소개했고, NVIDIA Omniverse는 구조화된 3D 장면과 시뮬레이션 도구 연결을 제공한다. 따라서 형식의 개수나 3D 화면만으로 세계적 차별성을 주장할 수 없다. ConT는 특정 사용자 작업에서 편집 성공·대상 일관성·재개 신뢰성을 측정해야 한다.

참고한 1차 자료 (2026-11-25 열람):
- [Google DeepMind, Genie 3 (2025-08-05)](https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/)
- [NVIDIA Omniverse](https://www.nvidia.com/en-us/omniverse/)

## 차별화 가설과 개발·측정 방법

| 가설 | 필요한 개발 | 사용자가 느낄 가치 | 측정할 증거 |
|---|---|---|---|
| 같은 대상의 여러 표현 | 공통 구조·부품 ID·조건·산출물 의존성, 2D/3D 대응 | 그림마다 다른 부품이 생기지 않고 설명과 구조가 이어짐 | 부품 누락·추가, 치수/명칭/버전 불일치율 |
| 가리켜서 바꾸는 편집 | 영역·부품·그래프 계열·단계 선택과 의미 연결 | “이것만 길게”, “이 단계만 느리게”가 실제 편집으로 이어짐 | 선택 해석 정확도, 편집 성공, 선택 밖 변경률 |
| 조건 변경의 결과 연결 | 변경 영향 판정과 도구 재실행, 이전/새 결과 비교 | 사용자가 같은 수정을 여러 화면에서 반복하지 않음 | 누락 갱신·불필요 재생성·오래된 결과 혼입 |
| 조작 가능한 4D | 시간/단계/조건축 분리, 카메라·재생 편집 | 움직임을 회전·단면·단계별로 이해하고 수정 | 시점 변경·단계 수정 성공, 동기 오차, 재열기 재현 |
| 현실 자료와 생성물의 연결 | 원본 자료·참조 좌표·계산 결과·버전 추적 | 설명이 어느 자료와 조건에 근거하는지 확인 가능 | 참조 누락/오연결, 값·단위 불일치, 범위 밖 요청 처리 |
| 오래 이어지는 작업 | 프로젝트 상태·선택·계획·산출물 저장, 재개·취소·실패 복구 | 종료하거나 모델을 바꿔도 작업을 이어 감 | 복원 성공, 중복 실행, 데이터 손실, 전체 작업 완료율 |

온도·응력 등 조건 변경의 물리 결과는 지원하는 계산·측정이 있을 때만 연결한다. 모든 생성 장면에 인과적 물리 정확성이 있다고 주장하지 않는다.

## 자체 역량을 쌓는 자리

기반 LLM·이미지 모델은 교체 가능한 도구로 연결한다. 자체 자산은 사용 권한을 확보한 작업 명세·대상 구조·사용자 수정·도구 실행·실패 복구·평가 데이터와 이를 다루는 소프트웨어다.

첫 학습 후보는 지시 대상 해석, 구조화된 계획, 장면/편집 명세, 도구 선택, 변경 영향 판단이다. 실제 실패가 반복되는 부분에서 규칙·프롬프트·기반모형·경량 보정/미세조정을 같은 평가셋으로 비교한 뒤 채택한다. 파운데이션 모델 사전학습이나 M05~M09 학습량을 제품 경쟁력의 유일한 지표로 삼지 않는다. 고객 자료를 허락 없이 공용 학습에 쓰지 않는다.

## 비교 가능한 제품 평가

본딩 첫 인수 흐름을 먼저 완성한 뒤 체결·관절 등 다른 대상으로 동일 작업을 비교한다. 같은 입력·참조 자산·작업 범위·출력 요구·시간/비용 조건을 고정하고, 일반 AI와 수동 도구 조합도 기준선으로 둔다.

보고할 지표는 전체 작업 완료율, 사용자가 다시 설명한 횟수, 선택 밖 변경, 결과 일관성, 저장/재개 성공, 첫 결과와 전체 완료의 지연시간(p50/p95), 성공 작업당 비용이다. 합격 수치는 초기 측정 뒤 확정한다. 한국어·영어 동일 과제와 기술 용어 보존을 확인하고, 평가 입력/출력 예·실패 사례·실행 버전을 공개 가능한 범위에서 함께 제시한다.

국제 사용에는 다국어·단위/좌표 일관성, 내보내기 호환성, 사용자별 데이터 분리, 로컬/서버 실행 선택, 설치·복구·모델 교체도 필요하다. 이들은 장기 사용을 가능하게 하는 제품 조건이며 기능 목록만으로 우위를 보장하지 않는다.
