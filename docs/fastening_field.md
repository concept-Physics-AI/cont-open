# 체결: 판 안의 응력 분포 (수치해석과 물리 이미지)

VDI 2230 식은 판이 눌리는 정도를 값 하나(판 컴플라이언스)로 낸다. 판 안에서 압축이 어떻게 퍼지는지는 보여 주지 않는다.
이 슬라이스는 같은 판을 유한요소로 풀어 **분포**를 내고, 그것을 **물리 이미지**로 그린다. "내부는 어떤 상태인가"에 그림으로 답하는 첫 단계다.

## 무엇을 푸는가

| 항목 | 내용 |
|---|---|
| 모양 | 구멍 뚫린 원통. 안지름 = 구멍, 바깥지름 = D_A, 높이 = 체결 길이. 두 판의 탄성계수는 따로 넣는다 |
| 하중 | 조립 체결력(대표 마찰)을 머리와 너트의 좌면 넓이에 고른 압력으로 위아래에서 건다 |
| 풀이 | 축대칭 선형 탄성, 네 절점 사각형 요소 (`src/cont/fem/axisym.py`) |
| 격자·푸아송비 | `config/fastening/default.yaml`의 `field` |

## 무엇이 나오는가 (`cont.packs.fastening.field.stress_field`)

- 물리장 둘: 판의 축 방향 압축 응력, 판의 등가응력
- 판 사이 면의 최대·평균 압력, 판 사이가 눌리는 반지름 (VDI 변형 원뿔이 닿는 반지름과 나란히)
- 판 컴플라이언스: 수치해석 값, VDI 식 값, 둘의 차이(%). **판정은 하지 않는다**
- 값의 지위: 해석. 물리잔차: 높이마다 단면이 받는 힘과 체결력의 어긋남 (격자 오차). 불확실성: 반영하지 않음

화면에서는 "응력 분포" 탭에 그림과 한 줄 요약으로 보인다. 그림 안에 지위, 계산 방법, 검증 상태를 적는다.

## 가정과 한계

- **볼트를 풀지 않는다.** 좌면에 고른 압력으로 바꿔 건다. 실제 머리는 단단해서 좌면 안쪽보다 바깥쪽 압력이 달라진다.
  이 가정 때문에 수치해석의 판 컴플라이언스는 VDI 식보다 크게 나온다 (예제 M10에서 +11.8%). 어느 쪽이 맞는지는 아직 말할 수 없다.
- **두 판은 붙어 있다.** 판 사이가 당겨지는 것으로 계산되는 곳은 실제로는 벌어진다. 그림에서 보라색으로 따로 칠한다. 그 바깥의 값은 믿을 수 없다.
- 선형 탄성이다. 좌면 가장자리의 높은 응력은 실제로는 눌려 퍼진다.
- 운전 하중과 열 하중은 걸지 않는다. 볼트 안의 응력 분포도 풀지 않는다.

## 확인한 것

- 풀이기: 닫힌 해가 있는 두 문제 (고른 압축을 받는 원통, 안쪽 압력을 받는 두꺼운 원통의 라메 해)와 맞는다.
- 체결 모형: 판 사이 면의 평균 압력 x 넓이가 체결력과 1% 안에서 맞는다. 응력은 체결력에 비례한다. 같은 판 두 장이면 분포가 위아래 대칭이다.
- **하지 않은 것**: 실측이나 다른 해석 프로그램과의 대조. 그래서 신뢰도는 "낮음", 검증 상태는 "검증 전"이다.

## 기준값 대조의 틀

`cont.packs.fastening.reference`가 두 가지를 한다. (1) `config/reference/fastening/`의 기준 사례를 계산해 편차를 보고한다. 사례는 **지금 비어 있다**: 표준 원문 없이 기억으로 적지 않았다. 출처가 없는 사례는 읽을 때 거부한다. (2) VDI 식과 수치해석의 판 컴플라이언스를 견준다(`cross_check`). 이것은 기준값과의 대조가 아니라 다른 두 방법의 비교다. 기본 허용 오차 프로파일에는 한계가 없어 어느 쪽도 판정하지 않는다.
