# 적층 1D 열응답 기준 (M07-A)

> 상태: 보조

한쪽 면의 온도를 바꿀 때 여러 층으로 쌓인 구조의 온도가 시간에 따라 어떻게 변하는지 계산하는 기준 풀이다. 코드는 `src/cont/packs/heat/stack.py`, 한계값은 `config/physics/heat_stack.yaml`. 실측과 비교하는 기능은 편차만 보고하고 판정하지 않는다.

## 지원 범위

| 항목 | 범위 |
|---|---|
| 차원 | 1차원(층에 수직 방향). 옆으로 퍼지는 열은 다루지 않는다 |
| 층 수 | 최대 8 |
| 물성 | 층마다 일정(온도에 따라 변하지 않음). 열전도율·밀도·비열 |
| 층 사이 | 접촉 열저항(㎡·K/W) 지정 가능. 첫 층에는 지정할 수 없다 |
| 경계 | 왼쪽 온도 고정. 오른쪽은 (온도 고정) 또는 (대류 계수와 주위 온도) 중 하나 |
| 온도 | 켈빈. 섭씨로 보이는 값은 거절한다 |
| 길이 | 미터. 한계를 넘는 두께는 단위 착오로 보고 거절한다 |
| 격자 | 층마다 최소 6칸, 전체 기본 120칸·최대 1000칸, 시간 걸음 기본 200·최대 4000 |

범위 밖 입력은 계산하지 않고 이유를 적어 거절한다(`OutOfScope`).

## 쓰는 법

`Stack(layers, t_left, t_initial, duration, t_right=…)`을 만들어 `solve_stack`에 넣는다. `steady_state`는 직렬 열저항 식으로 정상 상태 열유속을 준다. `convergence`는 격자·시간 간격을 줄였을 때의 관측 차수를 준다. `compare_response(sim_t, sim_temp, meas_t, meas_temp)`는 편향과 RMSE만 돌려주고 `judged: False`를 붙인다.

## 확인한 것과 한계

해석해(단일 층), 직렬 열저항, 2차 수렴, 에너지 수지를 시험으로 확인했다. 실제 접합 구조의 물성값은 넣지 않았다. 온도 의존 물성, 상변화, 2·3차원 효과는 범위 밖이다.
