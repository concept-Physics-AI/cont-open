# ConT가 쓰는 물리·수학 모형

ConT가 숫자를 내는 데 **지금 실제로 쓰는 모형**, 옛 저장소가 **적용하려던 모형**, 그리고 **앞으로 어떻게 구성할지**의 제안을 한곳에 적는다.

먼저 사실 하나. **지금 ConT에는 학습된 모형이 하나도 없다.** PINN도, 신경 연산자도, 대리모형도 없다.
모든 숫자는 해석식, 수치해석, 닫힌 식의 역산, 통계에서 나온다. LLM은 말만 다듬고 숫자를 만들지 않는다.

### 1.1 체결 해석식 (VDI 2230)

- 조임 토크와 체결력: M_A = F_M · (0.16 P + 0.58 d₂ μ_G + (D_Km / 2) μ_K)
- 볼트와 판의 컴플라이언스 δ_S, δ_P: 볼트는 머리·축·나사·너트 물림을 스프링의 직렬로, 판은 변형 원뿔과 슬리브로 본다
- 하중 분담: Φ = δ_P / (δ_S + δ_P). 운전 하중 F_A 가운데 볼트가 더 받는 몫은 Φ F_A, 판에서 줄어드는 몫은 (1 − Φ) F_A
- 볼트 등가응력: σ_red = sqrt(σ_z² + 3 (k_τ τ)²)
- 불확실성: 마찰계수의 범위를 그대로 흘려 체결력의 범위를 낸다 (구간 계산)

### 1.2 축대칭 유한요소

- 지배 방정식: 평형 ∇·σ = 0, 구성식 σ = D ε (등방 선형 탄성), 변형률 ε = (∂u_r/∂r, ∂u_z/∂z, u_r/r, ∂u_r/∂z + ∂u_z/∂r)
- 이산화: 네 절점 사각형 요소, 2 × 2 가우스 적분, 직접법으로 푼다
- 경계: 머리와 너트 좌면에 고른 압력. 볼트는 풀지 않고 두 판은 붙어 있다고 본다
- 확인: 고른 압축과 두꺼운 원통(라메 해)의 닫힌 해와 맞춘다. 물리잔차는 높이마다의 축력 평형이다

### 1.3 역문제 (복원)

- 관측 모형: Δl = δ_S · F + 잡음
- 추정: F = Δl / δ_S, μ = (M_A / F − 0.16 P) / (0.58 d₂ + D_Km / 2)
- 불확도: 1차 전파. u(F)/F = sqrt((u(Δl)/Δl)² + (u(δ_S)/δ_S)²), 범위는 표준 불확도의 2배
- 물리잔차: 추정한 체결력 − 토크 모형의 체결력. 식별가능성은 세 단계와 근거 숫자

### 1.4 지금 모형의 한계 (요약)

실측이나 다른 해석 프로그램과 대조한 것이 하나도 없다. 모든 결과가 "검증 전"이다. 체결의 수치해석은 볼트와 접촉(벌어짐)을 풀지 않는다.
역문제는 식 하나를 뒤집은 것이라 사전 지식(토크 모형)과 관측을 함께 쓰지 못한다. 절삭 재료 값은 원문과 대조하지 않았다.

### 2.1 문제의 정의: 숨은 상태의 복원

옛 저장소는 공정을 "예측"이 아니라 **숨은 상태를 복원하는 문제**로 정의했다 (O → S → Y).

- 숨은 상태장 S_t(x): 온도, 조성, 상분율, 변형률, 잔류응력, 경도, 위험도, **불확실성**까지 한 묶음
- 동역학: S_{t+Δt} = F_p(S_t, u_t, 형상, 재료, 경계조건; θ_p) + η_t
- 관측: O_t = H(S_t; θ_o) + ε_o (열화상, 열전대, 최종 경도 등)
- 품질: Y = G(S, u, 형상, 재료)
- What-if는 숫자 바꾸기가 아니라 **개입**이다: ΔY = G(F_p(do(u′))) − G(F_p(u))

### 2.2 구성: 물리 선생과 AI 쌍둥이

    실험·센서 O  →  보정 / 역문제
    물리 선생 (3D): 편미분방정식 + 상변태 속도식 + 열-금속-역학 결합      ← 정확하지만 느리다
      ↓ 상태장 말뭉치
    AI 연산자 쌍둥이: FNO / DeepONet / MeshGraphNet / PINO / 확산 모형(불확실성)   ← 빠르지만 문지기가 필요하다
      ↓ 거의 실시간의 what-if
    화면 → 공정 조건 추천

핵심은 **AI가 물리를 대신하지 않는다**는 것이다. 헌장 C3: "물리 선생이 먼저, 대리모형은 그다음. 증거 없이는 `trained_model=false`."

### 2.3 모형마다 정한 쓰임새

| 모형 | 쓰려던 곳 | 쓰지 않기로 한 곳 |
|---|---|---|
| PINN (물리 정보 신경망) | 드문 센서에서 숨은 상태 복원, 열전달계수의 역보정, 신경 연산자를 다듬을 때의 방정식 잔차 규제, 잔차장 만들기 | **PINN 하나로 3D 급랭 전체를 푸는 생산용 풀이기로 쓰는 것** |
| 신경 연산자 (FNO, DeepONet) | 입력 함수(형상, 재료, 초기 온도, 경계, 레시피) → 상태장 전체. what-if를 실시간으로 | 문지기 없이 쓰는 것 |
| PINO (물리 정보 신경 연산자) | 성긴 해석 데이터 + 고해상도 방정식 잔차로, 적은 고정밀 데이터로도 고해상도 예측 | |
| MeshGraphNet 등 형상 인지 모형 | 기어, 링, 샤프트처럼 격자(복셀)로 다루기 어려운 형상 | |
| 확산·생성 모형 | 불확실성(여러 가능한 상태), 후보 생성 | 물리의 근거로 쓰는 것 |
| 베이즈 복원 | p(x | y) ∝ p(y | x) p(x). 사후분포는 관측이 아니라 불확실성을 가진 추론 | |
| 세계 모형 | S_{t+1} = F(S_t, A_t). 행동에 따른 상태 변화 | 정본 상태를 따로 만드는 것 |
| 혼합 모형 | û = u_물리 + r_θ. 물리 예측에 학습한 보정을 더한다. 어느 몫이 물리이고 어느 몫이 학습인지 드러낸다 | 물리 실행 경로를 건너뛰는 것 |

손실은 PINN에서 L = L_관측 + λ·(방정식 잔차) + λ·(경계 잔차) + λ·(보존 법칙), PINO에서 L = L_선생 + λ·(방정식 잔차)로 적었다.

### 2.4 충실도 사다리와 보정 연산자

    F0 해석해 → F1 성긴 유한차분 → F2 중간 유한차분 → F3 축약 모형 → F4 상용 해석(FEM) → F5 보정한 실험·센서

학습은 S_높음 ≈ S_낮음 + Δ_θ(S_낮음, 형상, 재료, 조건)로 시작한다.
**"AI는 물리를 버리는 것이 아니라 낮은 충실도를 높은 충실도로 고치는 보정 연산자로 시작한다."**

### 2.5 문지기 (틀린 결과를 막는 장치)

- 모든 대리모형 출력에 불확실성장과 방정식 잔차장을 함께 낸다
- 학습 범위 밖(OOD)이면 물리 선생으로 되돌아간다
- 영향이 큰 결정은 해석·실험 충실도 문턱을 넘어야 한다. "대리모형은 후보를 내고, 선생이 승인한다"
- 알고리즘을 켜기 전에 밝힐 것: 실행 경로, 상태·증거 참조, 데이터와 모형의 계보, 잔차·충실도 점검, 불확실성·범위 밖·기권 동작, 사람 승인의 경계

## 3. 제안: ConT의 모형 구성

옛 설계의 원칙(물리 선생 먼저, 대리모형은 보정부터, 문지기 필수)은 그대로 가져오고, 지금 저장소의 크기에 맞게 다섯 층으로 놓는다.

| 층 | 무엇 | 언제 쓰나 | 지금 | 다음 |
|---|---|---|---|---|
| L0 해석식 | 표준·교과서의 닫힌 식 | 항상 먼저. 가장 빠르고 설명하기 쉽다 | 체결, 절삭 | 기준값 대조 (표준 원문 필요) |
| L1 수치해석 | 방정식을 격자에서 푼다 | 분포가 필요하거나 식의 가정이 깨질 때 | 판의 축대칭 탄성 | 볼트와 접촉(벌어짐)을 넣는다 |
| L2 복원 (역문제) | 관측 + 모형 → 숨은 값과 불확실성 | 센서가 있을 때 | 닫힌 식 하나 | **베이즈 복원**: 토크 모형을 사전 지식으로, 늘어남을 관측으로 써서 사후분포를 낸다 |
| L3 대리모형 | 선생을 흉내 내는 학습 모형 | **선생이 느릴 때만** | 없음 | L0 → L1의 보정 연산자부터 (아래) |
| L4 생성 | 설계 후보, 설명용 그림·영상 | 후보가 필요할 때 | 열거 탐색 | 조건부 생성 (나중) |

### 3.1 모형을 고르는 규칙

1. **닫힌 식이 있으면 식을 쓴다.** 식이 답하는 문제에 학습 모형을 쓰지 않는다.
2. **분포가 필요하면 수치해석을 쓴다.** 지금 체결의 축대칭 해석은 0.2초 안에 끝난다. 이 문제에는 대리모형이 필요 없다.
3. **센서가 있으면 복원한다.** 관측과 모형이 어긋나는 크기(잔차)와 식별가능성을 함께 낸다.
4. **선생이 느려질 때 대리모형을 붙인다.** 3D 접촉 해석, 여러 볼트, 시간에 따라 변하는 문제에서 그렇게 된다.
   그때도 처음부터 다 배우게 하지 않고, 빠른 모형(식)의 답을 느린 모형(수치해석)의 답으로 고치는 **보정 연산자**로 시작한다.
5. **대리모형은 문지기 없이 쓰지 않는다.** 잔차, 불확실성, 학습 범위 밖 표시, 선생으로 되돌아가기가 없으면 켜지 않는다.

### 3.2 PINN은 어디에 맞는가

- **체결에는 지금 맞지 않는다.** 방정식을 직접 푸는 편이 더 빠르고 정확하며 검증하기 쉽다.
- **맞는 곳은 "방정식은 알지만 경계조건이나 물성을 모르고, 센서가 드문" 장의 역문제다.**
  예: 금형 냉각에서 몇 개의 온도 센서로 내부 온도장과 열전달계수를 함께 찾는 문제.
  구조 문서의 물리 영역 순서에서 사출(금형 냉각 채널)이 세 번째이므로, PINN과 PINO는 그 영역에서 처음 쓰는 것이 맞다.
- 그때도 옛 설계가 정한 대로 **복원과 보정에 쓰고, 생산용 풀이기 전체를 대신하게 하지 않는다.**

### 3.3 첫 학습 모형은 무엇이어야 하는가

체결에서 가장 작게 시작할 수 있는 것은 이것이다.

- 선생: 볼트와 접촉을 넣은 축대칭 수치해석 (L1의 다음 단계)
- 데이터: 선생을 조인트 치수·재료·토크의 범위에서 수천 번 돌려 만든다. 실측이 아니라 "해석"으로 표시한다
- 모형: VDI 식의 판 컴플라이언스를 수치해석 값으로 고치는 보정 δ_P,해석 ≈ δ_P,식 · (1 + r_θ(치수 비))
- 문지기: 학습 범위 밖의 치수 비는 선생으로 되돌린다. 보정의 크기와 선생과의 차이를 결과에 적는다
- 쓸모: 설계 추천이 조합 수천 개를 훑을 때 식의 속도로 수치해석에 가까운 값을 쓴다

이것은 PINN이 아니라 작은 회귀 모형이다. 그래도 옛 설계가 말한 "보정 연산자로 시작한다"를 그대로 따르는 첫걸음이고, 문지기를 실제로 만들어 보는 자리다.

### 3.4 순서 (제안)

| 순서 | 일 | 필요한 것 |
|---|---|---|
| 1 | L2 베이즈 복원: 사전 지식 + 관측 → 사후분포, 식별가능성을 사후분포에서 | 없음 |
| 2 | L1 볼트와 접촉을 넣은 해석 | 없음 |
| 3 | L0 기준값 대조 | 표준 원문 |
| 4 | L3 보정 연산자와 문지기 (첫 학습 모형) | 2번이 끝나야 한다 |
| 5 | 실측과 대조 | 벤치 데이터 ([fastening_sensing.md](fastening_sensing.md)의 2단계) |
| 6 | PINN·PINO: 사출 금형 냉각의 역문제 | 영역 순서상 절삭 다음 |

## 4. 밖에서 확인할 수 있는 것

이 저장소는 개발 과정을 밖에서 확인할 수 있도록 공개한다 (대표 결정 2026-11-23).

- 모든 결과의 지위와 검증 상태: "해석", "추정", "검증 전"
