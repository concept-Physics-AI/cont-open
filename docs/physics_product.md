# Physics 제품: 첫 작업 흐름 제안

> 상태: 보류

**이 문서는 제안이다.** 대표가 정한 것은 Physics의 대상(해석 도구를 쓰는 설계자, 3D CAD 설계자, 소재 전공자)까지이고, 아래 작업 흐름은 지금 있는 엔진으로 먼저 해 볼 수 있는 것을 골라 적은 것이다. 정해지면 ARCHITECTURE.md를 먼저 고치고 이 문서를 "보조"로 바꾼다.

## 쓰는 사람

앤시스·아바쿠스 같은 도구로 해석하는 설계자, 3D CAD 설계자, 소재 전공자. 물리, 설계, 소재 특성은 잘 알지만 최신 AI는 잘 모른다. 이 사람에게 필요한 것은 AI를 설명하는 화면이 아니라 **자기 작업 안에서 AI가 돕는 자리**다.

## 후보 작업 흐름

| 후보 | 하는 일 | 지금 있는 엔진 | 모자란 것 |
|---|---|---|---|
| A. 숨은 상태 추정 | 잰 값(예: 볼트 늘어남)에서 직접 재기 어려운 값(체결력, 마찰계수)을 범위와 함께 추정하고 근거를 본다 | 있음 (체결, 합성 관측으로만 확인) | 실측 대조, 체결 밖의 영역 |
| B. 설계 후보 탐색 | 목표(예: 안전율)를 주면 만족하는 조합을 찾아 보여 준다 | 있음 (체결 설계 추천) | 체결 밖의 영역, 해석 도구와 연결 |
| C. 해석 결과 읽기 | 해석 도구가 낸 결과를 올려 분포와 숨은 상태를 같은 화면에서 본다 | 부분 (분포는 축대칭 판 해석만) | 외부 해석 결과 가져오기 |
| D. 치수에서 형상 | 치수를 말하면 형상 명세와 CAD 파일을 만들고 말로 고친다 | 있음 (볼트 조인트만) | 다른 형상 |
| E. 소재 특성 | 소재 값의 범위와 불확실성을 해석에 넣는다 | 없음 | 소재 엔진 전체 |

## 제안: 첫 흐름은 A + B를 체결 한 영역에서

- 엔진이 이미 있어 새 계산을 만들지 않고 전문가 작업 흐름을 먼저 시험할 수 있다.
- 순서: ① 잰 값과 조건 넣기 → ② AI가 추정한 값과 범위 보기 → ③ "이 값을 믿어도 되는가"(불확실성, 식별가능성, 검증 전) 확인 → ④ 목표를 주고 설계 후보 보기 → ⑤ 근거와 입력을 묶어 내보내기.
- 화면 규칙은 지금 규칙을 그대로 따른다: 값의 지위를 구분하고, 불확실성을 숨기지 않으며, 핵심 숫자는 셋까지, 판정 없이 편차만 보고한다.
- 서비스 층(`/v1/packs/{영역}/solve`)을 쓰는 첫 제품 화면으로 만들면 엔진과 화면이 섞이지 않는지 시험할 수 있다.

## 하지 않는 것

- 전문가를 대신해 판단하지 않는다. 결과는 계산값이며 검증 전이다.
- 외부 해석 도구(예: 상용 해석 프로그램)와의 연결은 이번 제안에 넣지 않는다. 형식과 권리 확인이 먼저다.
- 체결 밖의 영역은 Studio 일반화와 같은 순서로 넓힌다.

## 대표가 정할 것

1. 첫 흐름을 A + B(체결)로 할지, 다른 후보로 할지
2. 가장 먼저 쓸 전문가 (해석 설계자 / CAD 설계자 / 소재 전공자)
3. 외부 해석 결과를 가져오는 일(C)을 언제 넣을지
