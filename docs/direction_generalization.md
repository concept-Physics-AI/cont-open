# 방향: 체결 중심에서 일반 형태로

이 문서는 **기록**입니다. 구현 약속이나 일정이 아니고, 앞으로 전환안을 제시할 때 이 표를 고쳐 가며 씁니다 (2026-11-23 대표 지시).

## 지금의 상태

- 진열대(ConT FAB 고르기)의 상품 26개 가운데 대부분이 **체결(볼트 조인트)** 에서 나옵니다. 3D는 볼트 조인트 하나뿐이고, 물리 이미지는 모두 축대칭 판 해석 하나에서 나옵니다.
- 체결 화면은 ConT Studio를 만들기 위해 먼저 배우고 검토하는 **하나의 사례**입니다. Studio는 모든 물리와 일반 AI를 아우르는 곳이 되어야 합니다 (ARCHITECTURE.md).
- 그래서 지금의 이름과 구성에는 체결 전용 표현이 섞여 있습니다.

## 가려는 곳

상품을 **표현 방식(형태) · 물리량 · 대상**으로 나누어, 표현은 대상에 상관없이 공통으로 쓰고 대상(체결 조인트, 금형, 배관, 설비 …)은 입력으로 바꿉니다.

| 지금 (체결 전용) | 일반 형태로 바꾸면 | 바꾸려면 필요한 것 |
|---|---|---|
| 볼트 조인트 3D CAD | 치수 기반 부품 모델 | 대상별 형상 생성기 (지금은 볼트 조인트만) |
| 숨은 물리 3D | 물리량 표시 모델 | 대상과 물리량을 받는 입체 표시 |
| 축 방향 압축·등가·전단 응력 분포 등 | 색상 분포도 (물리량·범위·색을 고름) | 열, 유동, 접촉응력 같은 다른 해석 엔진 |
| 조이는 과정 · 조이는 과정 영상 | 과정 재생(하중 증가, 가열·냉각 …)과 해석 결과 영상 | 시간 해석 엔진, 재생 기준 표시 |
| 토크와 체결력 | 조건–응답 곡선 (가로·세로 물리량을 고름) | 입력과 결과를 일반 이름으로 받는 곡선 |
| 안전율 막대 | 기준 대비 비교 막대 (판정 없이 편차만) | 기준을 담는 프로파일 |
| 센서와 연결 추천 | 계측 연결 추천 | 대상별 계측 지식 |
| 신호 · 상태 추이 · 점검 안내 | 이미 일반적임 (가상 설비 기준) | 실제 설비 자료 연결 |

## 지킬 것

- 같은 엔진의 결과를 여러 표현으로 쓰되, **지원하지 않는 조합은 선택할 수 있는 것처럼 보이지 않습니다.**
- 카드 이름은 "응력 이미지 1"이 아니라 "응력 집중 영역", "냉각 과정 재생"처럼 **결과가 보이는 이름**으로 붙입니다.
- 물리 숫자는 엔진에서만 나오고, 판정 없이 편차만 보고합니다. 값은 검증 전입니다.
- 같은 계산 엔진을 Studio와 FAB이 함께 쓰고, 화면마다 계산을 따로 만들지 않습니다.

## 함께 정해야 할 것

- 산업군 분류 기준 (어떤 상품이 어느 산업에 쓰이는지)
- 다음에 만들 물리 엔진의 순서 (열 분포, 절삭 형상과 힘, 접촉응력 가운데)
- 표현 유형 체계(이미지·그래프·3D·4D·영상 각각의 세부 유형)를 카드로 옮기는 범위. 엔진이 있는 것부터 옮깁니다.
