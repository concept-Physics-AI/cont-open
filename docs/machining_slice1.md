# 절삭가공 팩: 슬라이스 1 (선삭의 절삭력)

체결 다음 물리 영역이다. 체결의 슬라이스 1과 같은 크기로, **계산 뼈대만** 넣는다. 화면과 대화는 다음 슬라이스다.

## 무엇을 계산하는가

바깥지름 선삭 한 번에 대해, 절삭 조건(지름, 절삭 속도, 이송, 절입, 절입각)과 재료에서 다음을 낸다.

| 값 | 식 |
|---|---|
| 칩 두께 h, 칩 폭 b | h = f sin(kappa), b = a_p / sin(kappa) |
| 비절삭저항 k_c | k_c1.1 * h^(-m_c) (키엔츨레 식) |
| 주절삭력 F_c | k_c * b * h |
| 주축 회전수, 토크, 절삭 동력 | n = 1000 v_c / (pi D), F_c D / 2, F_c v_c |
| 재료 제거율 | a_p * f * v_c |
| 이론 표면 거칠기 R_t | f^2 / (8 r_e) (공구 코 반지름을 주었을 때) |
| 가공 시간 | 길이 / (f n) (깎는 길이를 주었을 때) |

쓰는 법: `cont.packs.get("machining").solve({"cut": {...}})`. 결과는 공통 결과 형식(값의 지위: 해석, 조건과 재료 값은 입력)이다.

## 재료 값에 대한 주의

`packs/machining/tables/materials.yaml`의 비절삭저항은 **원문과 대조하지 않은 값**이다. 자료마다 값이 다르다.
그래서 표의 재료로 계산하면 근거에 그 사실이 적히고 신뢰도는 "낮음"이다. 공구 제조사 자료나 기계 편람을 받으면 값을 맞추고 `verified`를 바꾼다.
재료 표를 쓰지 않고 `specific_cutting_force`와 `exponent`를 직접 줄 수도 있다.

## 넣지 않은 것

- 경사각, 절삭 속도, 공구 마모에 따른 보정 계수 (모두 1로 본다)
- 이송 분력과 배분력, 절삭열, 떨림(채터), 공구 수명
- 밀링과 드릴링
- 불확실성(비절삭저항의 산포)과 물리잔차: "보고하지 않음"으로 나간다
- 판정: 기계 동력으로 깎을 수 있는지는 판정하지 않고 동력 값만 낸다
