## 1. 정의

| 구분 | 보이는 물리 | 숨은 물리 |
|---|---|---|
| 의미 | 직접 측정 가능한 상태 | 직접 측정하기 어려운 내부 상태 |
| 예 | 표면 온도, 외형 치수, 진동 신호, 공정 설정값, 카메라·열화상 영상 | 내부 온도장, 잔류응력, 내부 변형, 유동장, 계면 접합 상태, 미세 결함의 성장 |
| 얻는 방법 | 센서·계측·영상 | 관측 + 물리 모델 + AI 복원 (역문제 해석) |
| 결과의 지위 | 관측값 | 추정값. 불확실성과 물리잔차가 반드시 함께 있다 |

- **왜 중요한가.** 품질과 결함을 실제로 지배하는 것은 대부분 숨은 물리다. 제조에서 가장 값진 정보는 대부분 직접 잴 수 없다.
  관측에서 숨은 물리를 복원하고 신뢰 수준을 제시하는 것은 ConT에 연결할 전문 역량 중 하나다.
- **복원이란.** 관측 O에서 숨은 물리 상태 S를 구하는 역문제다: O가 주어졌을 때, 물리 제약 아래에서 `‖forward(S) − O‖²`를 가장 작게 하는 S.
- **품질로 바로 가지 않는다.** 관측에서 품질로 곧장 가지 않고 관측 → 숨은 물리 상태 → 품질(O → S → Y)로 간다.
- **가치 사슬.** 관측 → 복원 → 예측 → 생성 → 검증 → 의사결정. 복원의 결과는 하나의 정본 물리 상태에 쌓여 다음 단계의 입력이 된다.
- **관측과 상태는 다르다.** 관측은 상태를 구성하기 위한 증거 입력이고, 상태는 관측·모델·검증을 거쳐 구성된 것이다.

## 2. 상태의 지위

값마다 "어떻게 얻은 값인가"가 붙는다. 화면에서도 저장 구조에서도 구분한다.

| 지위 | 뜻 | 화면에서 함께 보일 것 |
|---|---|---|
| 관측 (Real / Observed) | 실제로 관측한 상태 | 관측 출처 |
| 추정 (Estimated) | 관측에서 복원한 숨은 물리 상태 | 불확실성, 물리잔차 |
| 해석 (Simulated) | 모델과 조건으로 계산한 상태 | 사용 모델, 가정, 조건 |
| 예측 (Predicted) | 미래 시점의 상태 | 예측 시점, 불확실성 |
| 생성 후보 (Generated) | 생성된 대안·가설 | 검증 전 후보라는 표시 |
| 설명용 (Presentation) | 계산 결과를 이해하기 쉽게 다시 꾸민 표현. 새 물리 값을 만들지 않는다 | 어느 근거 값에서 나왔는지, 물리의 근거가 아니라는 표시 |

## 3. 화면이 지켜야 할 규칙

1. **관측값과 복원값은 항상 구분된다.** 복원값을 관측값처럼 보이게 하는 표현은 금지다. 어떤 고급 표현도 이 구분을 흐리게 할 수 없다.
2. **불확실성과 물리잔차는 1급 정보다.** 요청할 때만 보이는 숨김 정보가 아니다. 표시를 생략하는 화면은 생략했다는 사실을 적는다.
   불확실성 없는 단일값은 과신을 만든다.
3. **LLM은 물리값을 만들지 않는다.** LLM은 대화·의도 해석·계획·설명을 맡고, 물리값은 관측·검증된 모델·솔버·복원 절차에서만 나온다.
4. **기본 화면은 간결하다.** 주 질문 1, 주 물리장 1, 그 위의 보조 물리장 최대 2, 핵심 숫자 최대 3, 주 동작 1.
   나머지는 눌러서 연다(서랍, 살펴보기 창). 저절로 뜨는 것은 진행 중인 작업을 가리지 않아야 하고 한 번에 하나만 뜬다.
5. **설명은 네 층이다.** 요약(모든 사용자) → 물리(엔지니어) → 수학·조건(전문가) → 증거·계보(검증자). 한 번의 동작으로 층을 오간다.
6. **주요 결과에는 믿을 근거를 함께 낸다.** 근거 데이터, 사용 모델, 가정, 경계조건, 검증 방법, 물리잔차, 불확실성, 적용 범위, 실패 조건.
7. **사용자의 물음에 맞는 표현을 쓴다.**

   | 물음 | 먼저 쓸 표현 |
   |---|---|
   | 지금 무슨 일이 일어나는가 | 말로 된 설명 + 관측 이미지·시계열 + 상태 요약 |
   | 내부는 어떤 상태인가 | 3D + 단면·등고선 + 불확실성 |
   | 왜 이런 일이 생겼는가 | 원인-결과 구조 + 상태 전이 + 근거 (후보·검증 중·검증 완료를 구분) |
   | 앞으로 어떻게 되는가 | 예측 상태 + 시간 애니메이션 + 불확실성 구간 |
   | 무엇을 바꿔야 하는가 | 바꾼 것과 안 바꾼 것의 비교 + 목적·제약 + 대안 순위 |
   | 이 결과를 믿어도 되는가 | 검증 결과 + 물리잔차 + 가정·조건 + 증거 |

8. **흐름.** 본다(현실·관측) → 이해한다(복원·해석·숨은 물리) → 설명한다(잔차·불확실성·증거와 함께 원인을 검토) →
   고친다(보정 후보) → 확인한다(바꾸기 전과 후). 화면에는 지금의 물리 → 숨은 물리 → 원인 → 후보 → 전후 비교 → 시간 변화 → 증거 순으로 나타나고, 한꺼번에 화면을 차지하지 않는다.
9. **"화면 고도화"는 미려한 UI가 아니다.** 복잡한 물리·수학·증거를 빨리 이해하게 만드는 정보 구조와 상호작용의 고도화다.

## 4. 체결에 옮기면

볼트 조인트에는 센서가 없다. 그래서 지금 체결 팩의 값은 "관측"과 "추정(복원)"이 아니라 **"입력"과 "해석"**이다. 이 차이를 숨기지 않는다.

| 값 | 층 | 지위 | 왜 |
|---|---|---|---|
| 조임 토크, 치수, 강도 등급 | 보이는 물리 | 입력 (설정값) | 사람이 정하거나 잴 수 있다 |
| 운전 하중 | 보이는 물리 | 입력 (가정) | 잴 수 있는 양이지만 지금은 사람이 넣은 값이다 |
| 조립 체결력 | 숨은 물리 | 해석 | 토크는 재지만 체결력은 직접 잴 수 없다. 마찰에 따라 달라진다 |
| 하중 분담, 남는 체결력, 볼트 응력, 좌면 압력 | 숨은 물리 | 해석 | 조인트 안쪽의 상태다 |
| 판이 눌리는 영역 | 숨은 물리 | 해석 모형의 가정 | VDI 2230이 가정하는 모양이다. 응력 분포를 구한 것이 아니다 |
| 안전율 | 결과 | 해석 | 숨은 물리에서 나온다 |
| 설계 추천 | | 생성 후보 (검증 전) | 같은 식으로 계산한 대안이다 |

- **불확실성**: 지금은 마찰 산포만 반영한다. 조립 체결력에 범위로 보이고, 남는 체결력·응력·안전율은 그 범위의 불리한 끝으로 계산한다.
- **물리잔차**: 닫힌 식이라 힘의 평형(볼트가 더 받는 힘 + 판에서 줄어드는 힘 = 운전 하중)은 0이다. 화면에 그렇게 적는다.
- **검증 상태**: 표준 예제·FEM과 대조하지 않았다. "검증 전"으로 표시한다.
- **진짜 "복원"이 되려면** 관측이 있어야 한다. 예를 들어 볼트의 늘어난 길이(초음파), 조임 각도, 와셔형 하중계의 값을 받아 체결력과 마찰계수를 거꾸로 구하는 일이다. 아직 없다.

읽기만 했고 파일은 옮기지 않았다. 필요한 대목만 아래에 옮긴다. 1~3절의 정본이 숨은 물리를 **화면에 어떻게 보일지** 정했다면, 이 문서는 **데이터로 어떻게 적을지**를 정한다.

**목적.** 관찰할 수 있는 데이터와, 직접 관찰할 수 없고 추정되는 데이터(숨은 물리)를 같은 형식으로 연결한다. 단, 두 종류를 엄격히 구분한다.

**데이터 계층 6단.**

| 단 | 이름 | 뜻 |
|---|---|---|
| 1 | 원 관측 | 센서, 카메라, 실험기, 로그에서 직접 얻은 값 |
| 2 | 처리한 관측 | 보정, 필터링, 특징 추출을 거친 값 |
| 3 | 계산한 물리량 | 여러 관측값으로 계산한 속도, 응력, 에너지 등 |
| 4 | 숨은 물리 추정 | 관측값과 물리 모델로 추정한 보이지 않는 상태·원인 |
| 5 | 가상 상황 | 조건을 바꿔 만든 상황 |
| 6 | 설명 자료 | 이미지, 그래프, 벡터장, 애니메이션, 리포트 |

**관찰 가능성 4종.** 직접(DIRECT), 간접(INDIRECT), 숨음(LATENT), 가상(COUNTERFACTUAL).

**숨은 물리 레코드가 반드시 갖는 것.** 추정값과 단위, 표준편차와 신뢰구간, 가설 순위, **증거 레코드**(어느 관측에서 나왔는가), 사용 모델, 잔차, **식별가능성 점수**, 신뢰 수준.
문서가 든 숨은 변수의 예: 내부 열원의 위치·세기, 재료 물성, 보이지 않는 내부 응력·손상도, 접촉면 압력·마찰계수·마모율, 공극률 등.

**신뢰도 원칙.** 숨은 물리의 값은 측정값이 아니라 모델 기반 추정이다. 모든 숨은 물리 레코드에 증거 레코드, 사용 모델, 잔차, 불확실도, 식별가능성을 반드시 넣는다.

**표현.** 같은 사건을 수치, 시간 변화, 공간 변화(2D/3D 장, 메시), 관계, 시각화(그림·영상), 설명으로 나란히 저장하고, 파생한 표현은 무엇에서 나왔는지를 기록한다.

**결과 품질.** 지표: 정확도(기준값과의 오차), 반복성, 재현성, 분해능, 표준불확실도, 신호 대 잡음비, 관측 범위, 결측 없는 비율, 물리 모델 잔차, 식별가능성.
등급: A(기준 시편·교정 완료·반복성 검증), B(측정값 양호·일부 불확실도), C(관측 가능하지만 잡음·결측·모델 의존), D(참고용·식별가능성 약함), E(검증 실패·사용 금지).
추정한 결과를 측정한 기준값으로 쓰지 않는다.

| 계산한 물리량 / 간접 | (관측에 넣어 둠) | **구분 없음.** 진단 팩의 통계가 여기에 해당한다 |

| (없음) | 입력, 생성 후보 | ConT가 더한 것 |

| 없는 것 | 어떻게 할지 |
|---|---|
| 증거 연결: 추정값이 어느 관측에서 나왔는지를 잇는 자리 | **넣었다.** 물리량마다 `evidence`(같은 묶음 안의 물리량 이름)를 적는다. 없는 이름을 가리키면 거부한다 |
| 식별가능성: 그 관측으로 그 값을 가려낼 수 있는 정도 | **넣었다.** 문서가 점수의 계산식을 정하지 않았으므로 점수를 지어내지 않고 세 단계(가려낼 수 있음 / 약함 / 가려낼 수 없음)와 근거 숫자로 낸다 (대표 결정 2026-11-23). 체결 추정에서는 추정값의 상대 표준 불확도가 근거이고, "약함"의 경계 25%는 잠정으로 둔 값이다 (`config/fastening/default.yaml`) |
| 품질 등급 A~E | 넣지 않는다. 기준 시편과 교정이 있어야 매길 수 있어 실측 데이터가 생긴 뒤에 다룬다 |
| 간접 관측의 구분 | 넣지 않는다. 지금 체결 팩에는 해당하는 값이 없다. 진단을 다시 다룰 때 본다 |
| 가설 순위 | 넣지 않는다. 지금은 한 값에 가설이 하나뿐이다 |
| 11개 물리 분류, 시나리오 묶음, 학습 데이터 | ConT 계산 팩의 범위 밖이다. 옮기지 않는다 |

## 6. 저장소에 주는 숙제

- ~~공통 결과 형식(PhysicsAnswer)에 지위와 물리잔차를 담는 자리가 없다.~~ **넣었다 (2026-11-23).** 값의 지위, 근거 데이터, 불확실성, 물리잔차,
  검증 상태, 적용 범위, 실패 조건이 형식에 들어갔고, 채우지 않은 항목은 "보고하지 않음"으로 나간다.
  정본의 다섯 지위에 **"입력"**을 더했다. 사람이 넣은 값과 표준 데이터는 관측도 계산도 아니어서 따로 불러야 관측값처럼 보이지 않는다.
  지금 팩이 적는 지위: 체결 계산은 해석(치수는 입력), 설계 추천은 생성 후보, 진단은 관측(관측 신호와 거기서 바로 낸 통계), 품질 예측은 예측.
  추정(복원)은 체결에 하나 생겼다: 볼트 늘어남 관측에서 체결력과 마찰계수를 구한다 ([fastening_estimate.md](fastening_estimate.md), 합성 관측으로만 확인). 진단 팩은 지위만 적었고 불확실성·잔차는 "보고하지 않음"이다 (진단은 D5에서 멈춘 샘플이라 더 채우지 않았다).
- 하나의 정본 물리 상태에 관측·추정·해석·예측을 쌓는 구조(옛 저장소의 Canonical Physical State, MPState)는 이 저장소에 아직 없다.
- 증거·검증 기록·계보를 따로 두는 구조도 아직 없다. 지금은 답변 묶음의 "근거" 글과 "신뢰도"가 그 자리를 대신한다.
