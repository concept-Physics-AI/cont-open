# 측정 CSV 입력과 편차 보고 (볼트)

> 상태: 보조

반복 측정 CSV를 읽어 엔진의 추정을 기준 값에 견주고 **편차를 보고**한다 (`src/cont/packs/fastening/intake.py`). 판정하지 않는다. 허용 오차는 정하지 않았다 (CLAUDE.md 규칙 6).

## 쓰는 법

    python -m cont.packs.fastening.intake <측정 CSV 경로>

CSV 파일은 저장소 밖에 둔다 (규칙 10). 한 줄이 한 번의 측정이다.

| 열 | 필요 | 뜻 |
|---|---|---|
| `specimen_id` | 필요 | 같은 시편을 반복해 잰 줄끼리 묶는다 |
| `torque_set_Nm`, `bolt_size`, `strength_class` | 필요 | 시편 안에서는 줄마다 같아야 한다 |
| `plate_1_thickness_mm`, `plate_2_thickness_mm` | 필요 | 판 두께 |
| `length_error_halfwidth_mm` | 필요 | 길이 한 번 읽을 때의 오차 반너비 (직사각형 분포로 본다) |
| `elongation_mm` 또는 `length_before_mm`+`length_after_mm` | 하나 이상 | 둘 다 있으면 서로 맞는지 확인한다 |
| `simulated_loadcell_force_N` 또는 `loadcell_force_N` | 선택 | 기준 체결력. 없으면 체결력 편차를 내지 않는다 |
| `force_error_halfwidth_N` | 선택 | 하중셀의 잔류 편향 반너비. 반복해도 줄지 않는 값으로 다룬다 |
| `effective_elastic_length_mm`, `tensile_area_mm2`, `elastic_modulus_MPa` | 선택 | 데이터가 가정한 값. 있으면 볼트 컴플라이언스를 견준다 |
| `data_origin` | 선택 | `SYNTHETIC`으로 시작하면 보고서에 합성이라고 적는다 |

## 계산한 것

- 길이 전후 두 번 읽은 차이의 계기 불확도 = sqrt(2) × 반너비 / sqrt(3) (두 읽기가 독립이라고 본 값. 같은 계기라면 상관이 있을 수 있어 실측에서는 따로 따져야 한다).
- 엔진의 추정(`fastening` 팩의 `estimate`)을 하중셀 평균에 견준 상대 편차, 하중셀 값이 엔진의 추정 범위 안인지 밖인지(사실 보고).
- 엔진의 볼트 컴플라이언스(VDI 2230)와 데이터의 `Leff/(E·A)`의 비율. 두 값은 정의가 다르다.

## 하지 않는 것

- 합격, 불합격을 판정하지 않는다. 프로파일이 한계를 정하면 그때 판정으로 이어진다.
- 합성 데이터로 엔진의 정확도를 검증했다고 말하지 않는다. 합성 표시가 있는 CSV는 보고서가 그렇게 밝힌다.
- CSV에 없는 값은 가정으로 적는다 (체결부 바깥지름, 판 탄성계수). 가정은 보고서 머리에 나온다.

## 합성 자료로 해 본 결과 (2026-11-24, 대표 제공 합성 묶음, 시편 10개)

체결력은 엔진 추정이 하중셀 값보다 **13~15% 낮았고**, 하중셀 값은 10개 모두 엔진의 추정 범위 밖이었다. 편차가 거의 일정한 것은 볼트 컴플라이언스의 정의 차이로 설명된다: 엔진 3.82e-6 mm/N 대 데이터 3.28e-6 mm/N (비율 약 1.16). 이 데이터는 단순식으로 만든 것이라 어느 쪽 모형이 맞는지는 가릴 수 없다. 실측을 받으면 컴플라이언스의 상대 불확도(지금 설정은 잠정값 5%)가 충분한지 먼저 본다.
